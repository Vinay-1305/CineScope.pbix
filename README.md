# 🎬 CineScope — IMDb Movie Data Analysis Dashboard

## 📊 Power BI Data Analytics Project

**CineScope** is an interactive **Power BI dashboard** built to analyze IMDb movie data and uncover insights related to movie performance, ratings, revenue, votes, genres, directors, runtime, and yearly trends.

The project transforms raw movie data into an interactive visual analytics dashboard using **Microsoft Power BI**.

---

## 🚀 Project Overview

The dashboard provides a comprehensive analysis of movie data through multiple interactive report pages.

It focuses on questions such as:

- How many movies are present in the dataset?
- What is the average IMDb rating?
- What is the total and average movie revenue?
- How does movie performance change over the years?
- Which genres have higher ratings and revenue?
- Which directors generate the highest revenue?
- Which movies receive the most votes?
- How does runtime relate to revenue and ratings?
- How do movie genres contribute to revenue over time?

## 📈 Dashboard Features

### 1. 🎯 Movie Overview

The overview page provides key performance indicators including:

- Total Movies
- Average Runtime
- Total Revenue
- Average IMDb Rating

It also includes yearly analysis of:

- Total Revenue
- Average IMDb Rating
- Number of Movies

---

### 2. 📅 Yearly Analysis

This page analyzes movie trends over time.

Visualizations include:

- Average Runtime by Year
- Movie Votes by Year

This helps identify changes in movie production and audience engagement across different years.

---

### 3. 🎭 Genre Analysis

The genre analysis section focuses on:

- Total Number of Genres
- Average Metascore
- Highest Revenue Genre
- Total Movies

It also compares genres based on different performance metrics.

---

### 4. 🎬 Director & Movie Analysis

This section explores movie performance at the director and title level.

Visualizations include:

- Total Revenue by Director
- Total Votes by Movie Title
- Total Revenue by Movie Title
- Detailed movie-level analysis

---

### 5. ⭐ Rating & Metascore Analysis

The dashboard analyzes:

- Average Metascore by Genre
- Votes by Genre
- Movie ratings
- Revenue performance
- Genre-level performance

---

### 6. 💰 Revenue & Performance Analysis

This section examines relationships between:

- Movie Rating
- Revenue
- Votes
- Genre
- Year

A scatter plot is used to visualize relationships between movie ratings, revenue, and audience votes.

---

### 7. ⏱️ Runtime & Revenue Analysis

The final analysis page investigates the relationship between:

- Runtime
- Average Revenue
- Average Rating
- Movie Title
- Year
- Genre

Visualizations include:

- Average Revenue and Rating by Runtime
- Average Rating and Total Revenue by Movie
- Total Revenue by Year and Genre
